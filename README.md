# Horizon — Biblioteca Web de Jogos

Biblioteca web independente, responsiva e em português para organizar uma coleção pessoal de jogos. Projeto próprio, sem afiliação ao Hydra Launcher.

## Recursos
- Pesquisa por nome e gênero
- Categorias e favoritos
- Biblioteca salva no navegador
- Importar e exportar a coleção em JSON
- Layout adaptado para celular e computador
- Publicação automática via GitHub Actions e GitHub Pages

## Publicação
Em **Settings → Pages**, selecione **GitHub Actions** como fonte. Depois abra **Actions** para acompanhar o workflow. O site será publicado após um push na branch `main`.

## Limites
O botão Jogar é demonstrativo: navegadores não executam diretamente programas `.exe`. A biblioteca é armazenada localmente neste navegador e não sincroniza entre dispositivos.
